# Hidden Hours Audit

**Find out how many hours a week your business spends on work that could run on its own, and which task to automate first.**

A survey of 1,000 UK small-business owners found they spend about **11 hours a week on admin**, roughly six working days a month ([Amex SME Business Barometer 2026, via Retail Times](https://retailtimes.co.uk/amex-sme-barometer-small-business-owners-spend-nearly-twice-the-time-on-admin-than-growing-their-business/)). Your number might be lower or higher. This worksheet helps you find out.

---

## Step 1: Keep a receipt for one normal week

For 5 working days, write down every repeated task and roughly how long it took. Don't change anything yet, just count.

| Task | Mon | Tue | Wed | Thu | Fri | Sat | Total hrs |
|------|-----|-----|-----|-----|-----|-----|-----------|
| Answering the same questions (price, stock, delivery, timings) | | | | | | | |
| Copying orders or bookings into a register / sheet | | | | | | | |
| Chasing payments and sending reminders | | | | | | | |
| Counting or updating stock | | | | | | | |
| Making the daily / weekly sales report | | | | | | | |
| Searching old chats for an order or a customer's details | | | | | | | |
| Sending invoices, receipts or confirmations | | | | | | | |
| *Your own task:* | | | | | | | |
| **Total for the week** | | | | | | | |

Tip: set a phone timer when you start a task. Guessing at the end of the day usually under-counts.

---

## Step 2: Score each task

Give every task a score from 1 to 3 on each question.

| Question | 1 | 2 | 3 |
|----------|---|---|---|
| **How often?** | weekly | a few times a day | all day |
| **Same steps every time?** | always different | mostly the same | exactly the same |
| **What happens if it's late?** | nothing | annoyed customer | lost sale or money |

**Add the three scores.** Tasks that score **7–9** are usually the best ones to automate first. Tasks that need judgement or a personal touch (complaints, negotiations, special requests) should stay with you.

---

## Step 3: Match the task to a fix

| If the task is... | A simple fix is usually... |
|-------------------|----------------------------|
| Same questions in chats | An auto-reply or AI agent on WhatsApp / Instagram / your website that answers with price, stock and an order link |
| Copying orders | Orders saved automatically to a sheet, database or simple app |
| Chasing payments | Scheduled, polite reminders with a payment link |
| Counting stock | Stock that updates every time an order is placed |
| Daily report | A summary sent to your phone at a set time |
| Searching old chats | One place with each customer's history and orders |

---

## Step 4: Before you talk to a developer

Bring these to the conversation:

- [ ] Your one-week totals from Step 1
- [ ] The top 1–2 tasks from Step 2
- [ ] Where the work happens today (WhatsApp, Instagram, Excel, a register, an existing app)
- [ ] Who on your team does it, and who should see the results
- [ ] One example of the task from start to finish (screenshots help)

Start with one task. Once it runs reliably, move to the next.
