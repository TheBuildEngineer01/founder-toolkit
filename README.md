# Founder Toolkit

**Free, practical guides, templates and starter code for founders and business owners planning software.** It covers what to build, what it should cost, and how to test an idea before spending on code.

Maintained by **Bilal | The Build Engineer**, an individual software developer in Lahore, Pakistan, building web apps, Flutter mobile apps, SaaS/MVPs, backends and AI automation for local and international clients.

*Turning ideas into smart digital solutions.*

---

## What's inside

| Guide | What it helps with | Type |
|-------|--------------------|------|
| [Shop System Checklist](./shop-system-checklist/) | 5 problems a simple shop system fixes (stock, udhaar, sales, profit) and what to prepare | Checklist |
| [Outgrowing WhatsApp](./outgrowing-whatsapp/) | 5 signs your business has outgrown running on chats, and what a simple system needs | Checklist |
| [Automation Checklist](./automation-checklist/) | 5 tasks businesses still do by hand, plus a scorecard to find what to automate first | Checklist |
| [Idea Validation](./idea-validation/) | 4 cheaper ways to test an app idea before building, plus a "time to build?" scorecard | Checklist |
| [App Quote Scope Checklist](./app-quote-scope-checklist/) | Why app quotes differ 10x, and a template to get comparable quotes | Checklist + template |
| [Inquiry Triage Starter](./inquiry-triage-starter/) | A small Python starting point for an automatic first reply to customer inquiries | Starter code |

New guides are added regularly. ⭐ Star the repo to keep up with them.
