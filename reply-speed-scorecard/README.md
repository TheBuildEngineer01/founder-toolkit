# Reply Speed Scorecard

**Find out how fast your business really replies to customers, which questions cost you the most sales, and what to automate first.**

Speed matters more than most owners think. In a 2026 survey of US buyers, **56% expected a reply within an hour, but only 36% got one, and 79% said they would switch to a business that responds faster** ([Invoca B2C Buyer Experience Report 2026](https://www.marketingdive.com/press-release/20260608-new-invoca-study-finds-consumers-wont-wait-ai-gives-brands-the-speed-to-w/)).

## Step 1: Keep score for one week

For 7 days, log every customer message on WhatsApp, Instagram, Facebook or your website. It takes 10 seconds per message.

| Day | Time message arrived | Channel | Question (in their words) | Time you replied | Minutes to reply | Did they buy? (Y/N/?) |

Tip: most chat apps show the time each message arrived, so you can fill this in at the end of the day.

Most businesses find the same pattern: the slower the reply, the lower the win rate. Your own numbers are the ones that matter.

## Step 3: Find the questions that get you "out"

Group the questions by type and count them:

| Question type | How many this week | Same answer every time? (Y/N) | Automate? |
|---------------|-------------------|-------------------------------|-----------|
| Price | | | |
| Is it available / in stock? | | | |
| Delivery charges / areas / time | | | |
| "Last price?" / discounts | | | |
| How to order / pay | | | |
| Order status / tracking | | | |
| Other: | | | |

**Rule of thumb:** if a question is asked often AND has the same answer every time, it's a good one to automate first. Keep the human touch for complaints, custom requests and negotiation outside your set rules.

---

## Step 4: Pick your "opening batsman"

| If most lost sales come from... | Start with... |
|----------------------------------|---------------|
| Late-night / weekend messages | An AI agent or auto-reply that answers price, stock and sends an order link |
| "Is it available?" | Stock that updates automatically and is visible to the agent or on your site |
| Delivery questions | A clear delivery-charges answer the agent sends instantly |
| "How do I order?" | An order link or a simple order form in the chat |
| People going quiet | An automatic, polite follow-up after a few hours |

Before going live: write down the answers you want it to give, your rules for discounts, and when it should hand the chat to you.
