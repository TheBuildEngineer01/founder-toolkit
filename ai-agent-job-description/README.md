# AI Agent Job Description

**Before you "hire" an AI agent for WhatsApp, Instagram or your website, write its job description. This template helps you decide what it should do, what it must never do, and when it hands the chat to you.**

Customers are ready for it: **54% of consumers say they're comfortable with automated text assistants** and **70% expect a business to reply within an hour** ([EZ Texting, 2026 Consumer Texting Behavior Report](https://eztexting.com/report/2026-consumer-texting-behavior-report)). A clear job description is what makes an agent helpful instead of annoying.

## 4. When to hand the chat to a human

The agent should pass the conversation to you (and tell the customer someone will reply) when:

- [ ] The customer is angry or complaining
- [ ] It's a refund, return or payment problem
- [ ] It's a custom order or special request
- [ ] The customer asks for a person
- [ ] It isn't sure of the answer
- [ ] Order value is above Rs. ____

## 5. Probation period (testing)

- [ ] Test it with 20–30 real past questions before going live
